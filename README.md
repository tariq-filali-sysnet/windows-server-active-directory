# Administration Windows Server & Active Directory (M202)

Compte rendu général des travaux pratiques réalisés pendant ma formation en **Infrastructure Digitale (option Systèmes et Réseaux)**.

📄 **Document complet :** [Compte rendu général M202 (PDF)](windows-server-active-directory.pdf)

## Contenu

### Partie A : Interface graphique (GUI)
- Déploiement d'un contrôleur de domaine AD DS (forêt `ntic.lan`)
- Intégration d'un poste client Windows 10 au domaine
- Surveillance avec System Insights
- Installation d'un contrôleur de domaine en lecture seule (RODC)
- Administration des unités d'organisation (OU)

### Partie B : PowerShell (Server Core)
- Mise en place d'un contrôleur de domaine avec PowerShell
- Gestion des objets Active Directory en PowerShell
- Administration des OU en PowerShell
- Création de groupes et d'utilisateurs (TECHLOG-CORP)
- Réinstallation d'un RODC sur Server Core

## Outils
Windows Server 2019, Active Directory Domain Services, DNS, PowerShell, Hyper-V, VMware Workstation, Windows 10
